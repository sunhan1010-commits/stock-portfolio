# 주식 포트폴리오 매니저

적금·예금·주식·ETF·현금을 한곳에서 관리하고, 종목 코드/이름만 넣으면
PER·PBR·ROE·배당수익률 등 기본 지표를 자동 조회해 **초보자용 신호등**으로
저평가/적정/고평가 수준을 보여주는 Windows 데스크톱 앱입니다.

- 한국 종목: 네이버 금융 (지연 시세)
- 미국 종목: yfinance (지연 시세)
- 데이터 저장: 로컬 SQLite (`portfolio.db`) — 인터넷 없이도 보유내역 유지

> ⚠️ 무료 지연 시세이며, 지표 기준은 업종·성장성을 배제한 단순 일반 가이드입니다.
> 투자 판단·매매 권유가 아닙니다.

## 실행 방법
- 콘솔과 함께 실행(오류 확인용): `run.bat` 더블클릭
- 창만 깔끔하게 실행: `주식앱_실행.vbs` 더블클릭
  - 바탕화면에 바로가기를 만들어 두면 편합니다.

## 기능
### 종목 분석 탭
- `삼성전자` / `005930` / `AAPL` 처럼 입력 → 자동으로 한국·미국 판별
- 현재가·시가총액·52주 위치, PER/PBR/ROE/배당수익률을 신호등으로 표시
- 각 카드에 마우스를 올리면 지표 설명 툴팁
- `＋ 포트폴리오에 추가`로 바로 보유내역 등록

### 포트폴리오 탭
- 종류별(주식/ETF/적금/예금/현금/기타) 자산 등록
- 주식·ETF는 수량·매입가 입력 → `🔄 시세 새로고침`으로 현재가·평가금액·손익 자동 계산
- 적금·예금·현금은 평가금액(잔액)만 입력
- 원/달러 환율로 통합 환산 후 **자산배분 비중(%)** 표시

## 지표 기준(초보자용 단순 가이드)
| 지표 | 저평가/우수 | 적정 | 다소 높음 | 주의 |
|------|------|------|------|------|
| PER | <10 | 10~20 | 20~35 | >35 |
| PBR | <1 | 1~2 | 2~4 | >4 |
| ROE | ≥15% | 10~15% | 5~10% | <5% |
| 배당수익률 | ≥4% | 2~4% | <2% | 무배당 |

## 문제 해결
- **SSL 인증서 오류**가 나면(보안 프로그램의 HTTPS 검사 환경):
  `.venv\Scripts\python.exe setup_certs.py` 실행 → `cacert.pem` 재생성
- 라이브러리 재설치: `.venv\Scripts\python.exe -m pip install -r requirements.txt`

## 파일 구성
- `app.py` — GUI (메인)
- `datasource.py` — 종목 데이터 조회(한국/미국)
- `metrics.py` — 지표 신호등 평가 기준
- `db.py` — SQLite 저장
- `certs.py` / `setup_certs.py` / `cacert.pem` — SSL 인증서 처리
